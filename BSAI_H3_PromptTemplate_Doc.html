1. Overview / 概述

📌 What it does / 功能简介

EN: This node provides a visual template browser for MiniMax H3 video generation prompts. Instead of writing complex prompts manually, users can select from pre-built, categorized templates with one click. The node includes a search function, cascading category selection, GIF preview, and optional customization textarea.

中文: 本节点为 MiniMax H3 视频生成模型提供可视化提示词模板浏览器。用户无需手动编写复杂的提示词，只需从预设的分类模板中一键选择即可。节点包含搜索功能、级联分类选择、GIF 预览动画、以及可选的补充修改文本框。

5. UI Interface Guide / 界面使用指南

🔍 Search Box / 搜索框

EN: Type any keyword (Chinese or English) to search across all template names, descriptions, and tags. Search results show the category path. Click a result to select it; the dropdowns will auto-sync.

中文: 输入任意关键词（中文或英文）搜索所有模板的名称、描述和标签。搜索结果显示分类路径。点击结果即可选中，下拉框会自动同步。

📂 Cascading Selection / 级联选择
  1. 分类 / Category — Select a top-level category (e.g., Image to Video, Expression Templates, Combat, Cinematic) / 选择一级分类（如图生视频、人物表情模板、武打打斗、电影运镜）
  2. 子类 / Subcategory — Select a subcategory (enabled after category selection) / 选择二级子类（选择分类后启用）
  3. 模板列表 / Template List — Click any template to add it to the selection stack / 点击列表中的任意模板即可加入已选叠加栈
🧩 Multi-Select Stacking / 多选叠加

EN: A mode switch ("多选叠加 / Multi-Stack") above the template list controls the selection mode. It is OFF (single-select) by default: clicking a template selects it and immediately shows its preview — for single-template previewing. Turn the switch ON to enter multi-select stacking (up to 5): click the base template first (e.g. 贴身缠斗 | Close Grappling), then click overlay templates (e.g. 环绕镜头 | Orbit (Arc Shot)) to enrich the result. The chips bar shows the stack in order; the 1st template is the base (scene/action), the rest are overlays (e.g. camera moves). Click × on a chip to remove it, or Clear to reset. Turning the switch back OFF keeps only the base template. The node merges all selected templates into one H3 prompt following the SKILL three-field structure: base scene/action + overlay camera directives appended, soundscape merged, music priority-filled.

中文: 模板列表上方有模式开关（"多选叠加 / Multi-Stack"）控制选择方式。默认关闭（单选）：点击模板即选中并立即显示其预览，便于单个模板预览。打开开关进入多选叠加（最多 5 个）：先点击基础模板（如"贴身缠斗 | Close Grappling"），再点击叠加模板（如"环绕镜头 | Orbit (Arc Shot)"）即可丰富画面效果。已选条按顺序展示叠加栈；第 1 个为基础模板（场景/动作），其余为叠加模板（如运镜）。点击 chip 上的 × 可移除，或点击"清除"重置。关闭开关时仅保留基础模板。节点会将所有选中模板合并为一个符合 H3 SKILL 三字段结构的提示词：基础场景/动作 + 叠加运镜指令追加，音效合并，音乐优先级补全。

🎬 Preview Area / 预览区域

EN: The right panel shows a GIF preview animation (if available), template name, generation mode, and duration info. If no GIF is available, a placeholder is shown.

中文: 右侧面板显示 GIF 预览动画（如有）、模板名称、生成模式和时长信息。若无 GIF 则显示占位提示。

✏️ Customization / 补充修改

EN: The textarea at the bottom allows you to append custom modifications to the selected template. Your text will be added after the template prompt with a separator. This is optional — leave empty to use the template as-is.

中文: 底部文本框允许你在选中模板后追加自定义修改。你的文本将在模板提示词后以分隔符添加。此为可选 — 留空则直接使用模板原样。

🔌 External Prompt Port / 外部提示词端口

EN: The external_prompt optional input port accepts a STRING from any other node (e.g., an LLM or a prompt rewriter). When provided, it OVERRIDES the template's action instead of being appended: for templates with 【ACTION】...【/ACTION】 markers the action text is literally replaced (e.g. input "抬腿" removes the walking clause and performs leg-lifting); all other templates get a strong "Action Override" directive injected into integrated_multimodal_description. Framing, camera, environment, lighting, timing and subject identity are always preserved.

中文: external_prompt 可选输入端口可接收任意其他节点（如 LLM 或提示词改写节点）输出的 STRING。输入后将覆盖模板中的动作而非追加：含【ACTION】...【/ACTION】标记的模板动作文本会被直接替换（如输入"抬腿"即删除行走描述并执行抬腿）；其余模板则在 integrated_multimodal_description 中注入强"动作覆盖"指令。构图、运镜、环境、光照、时间与主体特征始终保持不变。

🎤 Voice Input / 语音输入

EN: The 🎤 语音 / Voice button next to the search box opens a voice dialog. Click Start, speak into the microphone, then Stop & Transcribe. The recording is transcribed by a local offline Vosk Chinese model (vosk-model-small-cn-0.22) via the /bsai_h3/asr endpoint — no cloud, no API key. The editable result can be filled into external_prompt (action override) or user_customization. Requires a microphone permission; works over localhost/HTTPS. Model setup: python scripts/download_vosk_model.py (already included on this machine).

中文: 搜索框旁的"🎤 语音 / Voice"按钮可打开语音对话框。点击"开始录音"，对着麦克风说话，再点击"停止并转写"。录音由本地离线 Vosk 中文模型（vosk-model-small-cn-0.22）经 /bsai_h3/asr 接口识别——无需联网、无需 API Key。可编辑的识别结果可填入 external_prompt（覆盖动作）或 user_customization（补充修改）。需要麦克风权限；localhost/HTTPS 下可用。模型安装：python scripts/download_vosk_model.py（本机已内置）。

⚡ Direct Mode / 直通模式

EN: Inside the voice dialog, tick ⚡ 直通模式 / Direct Mode and click ⚡ 生成 H3 提示词 / Generate H3: the text in the box (voice transcription or manually typed) is expanded by a local llama.cpp GGUF LLM into a complete H3 three-field prompt following the official H3 prompt SKILL (time-coded shot breakdown, camera moves, soundscape, music) — Chinese input is translated to English. Then click ✅ 确定并输出 / Confirm & Output: the node outputs the prompt directly via prompt_output, bypassing all templates (name = "直通模式 | Direct Mode"). Auto flow (Direct Mode): while recording, 3 seconds of mic silence auto-stops and transcribes; after transcription a dialog asks「如何输出？/ How to output?」—「⚡ 直通输出原文 / Output raw text」sends the raw transcribed text downstream without H3 generation and auto-closes;「⚡ 生成 H3 提示词 / Generate H3」expands it into a full H3 three-field prompt first;「✏️ 修改文字 / Edit text」lets you edit before manual "Confirm & Output". The final prompt stays visible in the node's read-only「Output Preview」box after the dialog closes. First generation loads the model (~1 min for gemma-4-26B Q4); later calls are fast. The model is auto-detected (prefers ComfyUI/models/LLM/Gemma4-GGUF/gemma-4-26B-A4B-it-heretic-ara.Q4_K_M.gguf). Override with env BSAI_H3_LLM_MODEL (path to any GGUF), BSAI_H3_LLM_GPU_LAYERS (default -1 = all GPU), or set BSAI_H3_LLM_API_KEY + BSAI_H3_LLM_API_BASE to use an OpenAI-compatible API instead. The model stays resident while used — restart ComfyUI to free VRAM.

中文: 在语音对话框中勾选"⚡ 直通模式 / Direct Mode"并点击"⚡ 生成 H3 提示词"：对话框中的文字（语音转写或手动输入）将由本地 llama.cpp GGUF 大模型扩写为符合 H3 官方提示词 SKILL 的完整三字段提示词（分镜时间轴、运镜、音效、音乐）——中文输入自动翻译为英文。再点击"✅ 确定并输出 / Confirm & Output"，节点将直接通过 prompt_output 输出该提示词，绕过所有模板（名称显示"直通模式 | Direct Mode"）。自动化流程（直通模式）：录音时 3 秒无声音将自动停止并转写；转写完成后弹出询问框「如何输出？」——「⚡ 直通输出原文」不经过 H3 生成，直接把语音转文字原文输出给下游、窗口自动关闭；「⚡ 生成 H3 提示词」由本地大模型按 H3 三段式标准扩写后输出；「✏️ 修改文字」可先编辑再手动「确定并输出」。输出后可在节点下方「输出提示词预览 / Output Preview」只读窗口查看发送给下游的完整提示词（窗口关闭后仍保留）。首次生成需加载模型（gemma-4-26B Q4 约 1 分钟），之后即时响应。模型自动检测（优先 ComfyUI/models/LLM/Gemma4-GGUF/gemma-4-26B-A4B-it-heretic-ara.Q4_K_M.gguf）。可通过环境变量覆盖：BSAI_H3_LLM_MODEL（任意 GGUF 路径）、BSAI_H3_LLM_GPU_LAYERS（默认 -1 = 全部 GPU）、或设置 BSAI_H3_LLM_API_KEY + BSAI_H3_LLM_API_BASE 改用 OpenAI 兼容 API。模型常驻显存，重启 ComfyUI 可释放。

9. Latest Upgrade / 最新升级说明

💬 Direct-Mode Confirm Dialog + Output Preview (v1.11.1) / 直通模式询问框与输出预览

EN: In Direct Mode, after the mic stops and the speech is transcribed, a dialog asks「如何输出？/ How to output?」—「⚡ 直通输出原文 / Output raw text」sends the raw transcribed text straight to downstream nodes without H3 generation, then auto-closes;「⚡ 生成 H3 提示词 / Generate H3」expands it into a full H3 three-field prompt per the H3 SKILL via the local LLM, then outputs downstream;「✏️ 修改文字 / Edit text」lets you edit before manual "Confirm & Output". 10. Tips & Notes / 使用技巧与注意事项

✅ Expression Templates / 表情模板:
  • EN: Expression templates use single-shot, no-cut continuity. The prompt explicitly locks the camera to a close-up framing.
  • 中文: 表情模板使用单镜头一镜到底的连续性。提示词中明确锁定为特写构图。
  • EN: For grief/restraint templates, mouth-corner safety rules are applied: "嘴角全程不上扬" prevents the model from generating unintended smiles.
  • 中文: 悲伤/克制类模板应用了嘴角安全规则："嘴角全程不上扬"可防止模型生成意外的微笑。
  • EN: Micro-expression templates use 4-beat structure: Baseline → Leakage → Recovery → After-state, with normal-speed timing density.
  • 中文: 微表情模板使用四拍结构：基线 → 泄露 → 压回 → 收束，时间节拍密度为正常速度。
✅ Search / 搜索功能:
  • EN: Search matches template names (CN+EN), descriptions, tags, category and subcategory names.
  • 中文: 搜索匹配模板名称（中英文）、描述、标签、分类和子类名称。
  • EN: Search has a 200ms debounce delay for performance.
  • 中文: 搜索有 200ms 防抖延迟以提升性能。
⚠️ Important / 重要事项:
  • EN: If no template is selected, the node outputs the customization text (or empty string) as the prompt.
  • 中文: 若未选择模板，节点将输出补充修改文本（或空字符串）作为提示词。
  • EN: The user_customization text is appended AFTER the template prompt, separated by a marker line.
  • 中文: 补充修改文本追加在模板提示词之后，以分隔标记行隔开。
  • EN: Expression templates with needs_image=true require a portrait image input for best results.
  • 中文: needs_image=true 的表情模板需要人物图片输入才能获得最佳效果。

11. FAQ / 常见问题

Q: The node shows empty / blank / 节点显示空白

EN: Make sure the web/templates_data.json file exists and is valid JSON. Try refreshing the browser page (Ctrl+F5).

中文: 确保 web/templates_data.json 文件存在且为有效 JSON。尝试刷新浏览器页面（Ctrl+F5）。

Q: Preview WebP not showing / 预览动画不显示

EN: 25 templates currently ship with animated preview WebPs; the rest show a 🎬 placeholder. You can still use any template — the preview is only a visual aid. If a preview fails to load, hard-refresh the browser (Ctrl+F5) or check that the WebP exists in web/previews/.

中文: 当前有 25 个模板附带动图预览 WebP；其余显示 🎬 占位符。你仍然可以使用任何模板 — 预览只是视觉辅助。若预览无法加载，请强制刷新浏览器（Ctrl+F5）或检查 WebP 是否存在于 web/previews/。

Q: How to add my own templates / 如何添加自定义模板

EN: Edit templates/prompt_templates.json and add your template under the appropriate subcategory. Then copy the file to web/templates_data.json and refresh the page.

中文: 编辑 templates/prompt_templates.json，在相应子类下添加你的模板。然后将文件复制到 web/templates_data.json 并刷新页面。

Q: Dropdowns don't sync after search / 搜索后下拉框不同步

EN: Clicking a search result should automatically sync the category and subcategory dropdowns. If it doesn't, try clearing the search box first.

中文: 点击搜索结果应自动同步分类和子类下拉框。如未同步，尝试先清空搜索框。

Q: Voice button says transcription failed / 语音转写失败

EN: Make sure vosk is installed (pip install vosk) and the model exists (python scripts/download_vosk_model.py). The mic requires HTTPS or localhost. If the error mentions the model, run the download script and restart ComfyUI.

中文: 请确认已安装 vosk（pip install vosk）且模型已就位（python scripts/download_vosk_model.py）。麦克风需要 HTTPS 或 localhost 环境。若报错提示模型缺失，运行下载脚本并重启 ComfyUI。
